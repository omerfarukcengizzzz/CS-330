# CS-330 Module Eight Journal Reflection

## How do I approach designing software?
Working on this project helped me develop a structured approach to designing 3D objects using OpenGL.

- New design skills learned: I improved my ability to visualize and construct 3D models using basic geometric shapes. For my cologne bottle, I used a rectangular prism for the body and a cylinder for the cap. I also experimented with glPolygonMode(GL_LINE) to render wireframes, which helped me see the structure more clearly.
- Design process followed: I started by analyzing the object’s structure and figuring out how to model it using OpenGL’s primitives. I then implemented the model in SceneManager.cpp, adjusting its scale, position, and proportions as needed.
- Applying design tactics in the future: The skills I developed in breaking down complex objects into simple components will be valuable for future projects involving game development, CAD modeling, or AR/VR applications.

## How do I approach developing programs?
Developing the 3D scene was an iterative process that involved structured programming, debugging, and refinement.

- New development strategies used: I took a modular approach, implementing each component separately before integrating them into the full scene. Debugging was mostly visual—I adjusted transformations and tested different values until the proportions looked right.
- Iteration’s role in development: Iteration was key to refining the model. After rendering the initial version, I realized that the proportions were off, so I made adjustments to scaling, positioning, and transformations to improve accuracy. I also tested different lighting and shading techniques to enhance the final look.
- Evolution of development approach: At first, I focused on just getting the shapes to render correctly, but as I progressed, I optimized my workflow by structuring my transformations and improving object placement.

## How can computer science help me in reaching my goals?
This project reinforced how computational graphics skills can be applied in both academic and professional settings.

- New knowledge and skills for education: Learning about 3D transformations, rendering techniques, and OpenGL programming has strengthened my understanding of computer graphics. These skills will be useful for future coursework and personal projects related to simulations or game development.
- New knowledge and skills for a professional pathway: Understanding 3D rendering and visualization is valuable in industries like gaming, UI/UX design, and simulation development. These skills can also be applied in fields like AI-driven image processing and data visualization, expanding potential career opportunities.
